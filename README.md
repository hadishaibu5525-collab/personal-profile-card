# Personal Profile Card

A simple, responsive personal profile card built with HTML and CSS as part of my journey into web development.

## About the Project

This project displays a personal profile, a short biography, a list of skills, and links to my online profiles.

I built it to practise HTML structure and learn how to style web pages using CSS.

## Built With

- HTML5
- CSS3

## Features

- Profile photo
- Personal introduction
- Skills list
- Links to email, GitHub, and LinkedIn
- Responsive layout
- CSS hover effects

## What I Learned

- Structuring a webpage with HTML
- Styling elements with CSS selectors
- Using padding, margin, borders, and box shadows
- Centering content with Flexbox
- Styling links and adding hover effects
- Making a layout adapt to smaller screens

## How to View the Project

1. Clone or download this repository.
2. Open `index.html` in a web browser.
